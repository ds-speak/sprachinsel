# Sprachinsel

Lern-App für brasilianisches Portugiesisch: 18 Sprachinseln mit 1.042 Sätzen, Hören mit der ElevenLabs-Stimme Lair, Verbtrainer für alle Hauptzeitformen und Lernkarten mit Wiederholung in Abständen.

App öffnen: https://ds-speak.github.io/sprachinsel/

Auf dem iPhone in Safari öffnen, dann „Teilen“ → „Zum Home-Bildschirm“. Der Lernstand bleibt auf dem Gerät.
